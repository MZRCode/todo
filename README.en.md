# 📝 Todo+ Usage Guide
This repository includes custom task templates for the [**Todo+**](https://marketplace.visualstudio.com/items?itemName=fabiospampinato.vscode-todo-plus) extension.  
It is designed to help you easily track your tasks, projects, habits, and daily plans.

---

## 📦 Contents
This repository contains two main `.todo` files:

- [**features.todo**](https://github.com/MZRCode/todo/blob/main/features.en.todo)
  A short summary and examples of all features provided by the Todo+ extension.

- [**template.todo**](https://github.com/MZRCode/todo/blob/main/template.en.todo)
  A task planning template organized under categories such as daily life, work, and personal development.

## ⚙️ How to Use
1. Install the Todo+ extension in VSCode.
2. Download the `.todo` files from this repository or add them to your own project.
3. When you open the file, Todo+ will automatically recognize the syntax.
4. Manage your tasks using the symbols: `☐`, `✔`, and `✘`.
5. Add time estimates, priority, and other tags to enhance your workflow.  
   Example: `☐ Review the code @1h @high @today`

---

## 🧠 About Tags
Todo+ allows you to add various meta tags to your tasks:

| Tag              | Description                      |
|------------------|----------------------------------|
| `@today`         | Marks the task for today         |
| `@done`          | Completion time                  |
| `@started`       | Start time                       |
| `@lasted`        | Duration of the task             |
| `@est`           | Estimated time                   |
| `@critical`      | Critical task                    |
| `@high`, `@low`  | Priority level                   |
| `@1h`, `@30m`    | Time estimation indicators       |
