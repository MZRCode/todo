## ⚙️ Nasıl Kullanılır?
1. VSCode'a Todo+ eklentisini kurun.
2. Bu repodaki `.todo` uzantılı dosyaları indirin veya kendi projenize dahil edin.
3. Dosyayı açtığınızda Todo+ otomatik olarak sözdizimini tanıyacaktır.
4. Görevlerinizi `☐`, `✔`, `✘` sembolleriyle yönetin.
5. Zaman, önem seviyesi ve diğer etiketleri kullanarak detaylandırma yapabilirsiniz.  
   Örnek: `☐ Kodları gözden geçir @1h @high @today`

---

## 🧠 Etiketler Hakkında
Todo+ görevlerinize çeşitli meta etiketler eklemenize olanak tanır:

| Etiket         | Açıklama                        |
|----------------|---------------------------------|
| `@today`       | Bugünün görevi                  |
| `@done`        | Tamamlanma zamanı               |
| `@started`     | Başlama zamanı                  |
| `@lasted`      | Ne kadar sürdü                  |
| `@est`         | Tahmini süre                    |
| `@critical`    | Kritik görev                    |
| `@high`, `@low`| Öncelik seviyesi                |
| `@1h`, `@30m`  | Tahmini süre belirteci          |
